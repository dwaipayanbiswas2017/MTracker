MCP Help

Connect AI assistants like Claude Desktop to your MTracker data. Server: {{ server_info.name }}/{{ server_info.version }} · Protocol {{ supported_versions|join(', ') }} (negotiated)

Quickstart — 3 steps

  1. 1 Create an API key on the API Keys page. Copy it immediately — it is shown only once.
  2. 2 Paste it into your MCP client's configuration (examples below).
  3. 3 Restart the client and ask about your finances — e.g. “How much did I spend last month?”

Connection endpoints

Endpoint Method Purpose
{{ sse_url }} GET SSE stream (server → client)
{{ messages_url }} POST JSON-RPC requests (client → server)

Both endpoints require the header Authorization: Bearer mt_live_…

Key scopes

Scope Allows
read Read-only tools: summaries, month data, balances, lists, profile. Safe for analysis-only clients.
read_write Everything in read, plus creating expenses, transfers, debts, months, notes and profile updates.

Client setup

{ "mcpServers": { "mtracker": { "command": "npx", "args": [ "-y", "mcp-remote", "{{ sse_url }}", "--header", "Authorization: Bearer mt_live_PASTE_YOUR_KEY_HERE" ] } } }

Config file: claude_desktop_config.json. Requires Node.js (npx) — the mcp-remote wrapper bridges Claude Desktop to this SSE server. Restart Claude Desktop after saving.

{ "inputs": [ { "type": "promptString", "id": "mtracker-pat", "description": "MTracker Personal Access Token (starts with mt_live_)", "password": true } ], "servers": { "mtracker": { "type": "sse", "url": "{{ sse_url }}", "headers": { "Authorization": "Bearer ${input:mtracker-pat}" } } } }

File: .vscode/mcp.json in your workspace. VSCode prompts once and stores the key in the OS credential store — never hard-code the raw key here. Then run MCP: List Servers → start mtracker.

Troubleshooting

Connected but no tools listed
This happens when the client and server cannot agree on a protocol version. The server negotiates across {{ supported_versions|join(', ') }} — make sure you deployed the latest server code, then restart/reconnect the client (in VSCode: "MCP: List Servers" → restart).
401 Unauthorized
The key is missing, mistyped, revoked, or expired. Check the Authorization: Bearer … header and create a fresh key on the API Keys page.
"Read-only token cannot perform write operations"
Your key has the read scope. Create a read_write key for actions that modify data.
SSE stream disconnects
Reconnect the client — each connection gets a fresh session. Stale server-side sessions are cleaned up after 5 minutes.
I lost my key
Keys are shown once and cannot be recovered. Revoke the old key and generate a new one.

Security best practices

  • Prefer the read scope unless the client must write data.
  • Never share keys or commit them to code repositories.
  • Revoke keys you no longer use — revocation takes effect immediately.
  • If a key leaks, revoke it and generate a replacement.
